# create-captra

Create a full-stack Captra application with TypeScript, React, a Node runtime, typed HTTP transport, scoped memory, component views, tests, and the Captra startup experience.

```bash
npx create-captra my-app
cd my-app
npm install
npm run dev
```

The generated project includes separate browser and server entry points, a typed capability contract, a component registry, and build/test scripts.
