# @captra-ai/devtools

Inspectable React views for Captra runs, ordered events, checkpoints, memory, shared state, model traces, budgets, and usage.

Use `CaptraDevtools` for an individual replay, `CaptraUsage` for aggregated provider, model, capability, user, tenant, or run reports, and `CaptraConversations` to inspect conversation metadata and lifecycle state.

```bash
npm install @captra-ai/devtools
```

The same API is available from the `captra/devtools` entry point in the umbrella package.
