# @captra-ai/devtools

Inspectable React views for Captra runs, ordered events, checkpoints, memory, shared state, model traces, budgets, and usage.

This package is currently developed inside the Captra repository and is not yet published as a standalone public package. Use the `captra/devtools` entry point from the umbrella package where available.
