# Roadmap

Captra is an early developer preview. The roadmap prioritizes adoption evidence and stable boundaries over accumulating primitives.

## 0.5 — Developer preview

- Complete documentation site and API reference
- Official Next.js and worker starters
- Local run inspector for tools, memory, state, events, and checkpoints
- Security and tenant-isolation guidance
- Production reference application

## 0.6 — Integration preview

- Additional model providers
- Authentication, database, observability, and SaaS plugins
- Plugin compatibility tests
- Node, serverless, edge, and worker deployment recipes
- Load and recovery suites

## 0.7 — Stability preview

- Versioned wire protocol and event schema
- Stable model, state, memory, run, and queue adapter contracts
- Upgrade tooling and migration guides
- Cross-platform CI and support policy
- Security review and dependency scanning

## 1.0 readiness

The primary contracts are stable, upgrades are documented, the reference application has production evidence, and third-party plugins can target a declared compatibility range.

See the repository [roadmap](https://github.com/VaibhavBansal26/captra/blob/main/ROADMAP.md) for the maintained source.
